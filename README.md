# stock-indices-tracker

Application web simple et moderne pour consulter les indices boursiers, avec un tableau de bord et une vue de détail.

## Objectif

Ce projet sert de démonstration de site web de consultation des indices boursiers, prêt à être publié gratuitement sur GitHub Pages.

## Structure

- `index.html` : structure de la page
- `styles.css` : style du site
- `script.js` : données et interactions

## Utilisation

Ouvrez `index.html` dans votre navigateur pour voir le site.

## Publication gratuite

1. Pousser ce repository sur GitHub.
2. Dans le dépôt, aller dans `Settings > Pages`.
3. Choisir la branche `main` et dossier `/root`.
4. Le site sera publié sur une URL de type :
   `https://votre-utilisateur.github.io/stock-indices-tracker`

## Remarques

Les données sont actuellement mockées pour tester le concept. Vous pouvez ensuite les relier à une vraie API boursière pour un usage en production.
